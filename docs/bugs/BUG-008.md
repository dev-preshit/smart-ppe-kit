# BUG-008 Motor pin back HIGH for 231 ms across a scan-stall restart (safe off undone by the motor task, B-01/M-08 not met)

| Field | Value |
|---|---|
| Severity | P1 (motor safety, NFR-05 'low at boot', B-01, M-08) |
| Status | Fixed (fix approved by Preshit 2026-11-23); retest by the TC-74 1 h re-run |
| Reported by / date | S5 engineer (Claude Code session), 2026-11-23 |
| Found in | TC-74 evidence run, test_logs/S5/TC-74_f38ed18.log (FAIL row in summary_s5.csv), firmware FW hub=bbade3e7 common=f27ca4fc |
| Requirement(s) | NFR-05, FR-30 |
| State machine transition(s) | M-08 (output low before the restart), B-01, X-01 (scan reboot) |
| Finding link (if related) | BUG-007 (same flag) |

## Environment
- Hub bench build at f38ed18 (code of f971297), recorder tools/edge_recorder on COM8, calibrated the same sitting (CAL-recorder_f38ed18.log, 13 us).

## Steps to reproduce
1. `python tools/s5_motor.py tc74 --hub COM3 --rec COM8` (alert running, `stall 3` every 4th fault).
2. The scan-stall reboot calls hub_motor_safe_off() and then ESP.restart(). If the 1 ms motor task runs in between, it re-starts the alert pattern.

Reproducibility: timing dependent; 1 of 11 scan-stall reboots (and 0 of 11 reset / 11 wdt) in the 1 h run.

## Expected (SRS acceptance criterion)
NFR-05: the output is low at boot; M-08: output low before the restart.

## Actual
TC-74_f38ed18.log, fault stall 22: line 4718 'SCAN reboot', line 4726 pin LOW (safe off, t=3042310798 us), line 4727 pin HIGH again 0.9 ms later (t=3042311670), line 4731 LOW at t=3042543090 (231 ms, during the boot, before 'HUB boot'). Longest ON of the run stayed <= 400 ms.

## Analysis
- Root cause: hub_motor_safe_off() set the motor FSM idle (boot()) but the alert request g_alert_req was still true; the motor task's next tick called set_alert(true) and pattern_step() drove the pin high before ESP.restart() took effect; the level then held through the restart until hub_motor_early_init().
- Why earlier tests did not catch it: a race of about 1 ms per restart; TC-30b and the rehearsals each had only one or two scan-stall reboots.

## Fix
- hub_motor_safe_off() also sets g_force_low (the BUG-007 flag); drive() then keeps the pin low until the restart. safe_off is only called right before ESP.restart().
- Approved requirement change needed? No (implements M-08 as written).

## Regression
- TC-74 1 h re-run (about 11 scan-stall reboots) at the fixed firmware; its analyzer fails on any rise between a chip reset and the re-armed alert.
